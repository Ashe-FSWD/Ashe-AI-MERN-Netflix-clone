3. ⏱️ Debounced Live TMDB Search Hook (useDebounce)
Files: 
src/hooks/useDebounce.js
 & 
src/App.jsx
Real-World Production Context:
In high-traffic production apps, firing an API request on every keystroke causes backend query flooding, risks hitting rate limits (HTTP 429 Too Many Requests), and creates race conditions where older slow responses overwrite newer responses.

How It Works:
Delays sending search queries to TMDB (/search/multi) until the user pauses typing for 400ms.
Reduces network API traffic by >80% and ensures instant, smooth search results.
