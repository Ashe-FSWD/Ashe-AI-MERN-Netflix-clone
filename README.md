# 🎬 Netflix Clone

A Netflix-inspired web application built as a practical project to apply my web development skills and showcase my progress in my professional portfolio.

## 👨‍💻 Author

**Ashenafi Elias**

## 🎓 About the Project

After completing the **AI-Powered Evangadi Bootcamp**, I developed this Netflix Clone as part of my project-based learning journey.

The purpose of this project is to apply the knowledge I gained, strengthen my frontend development skills, practice working with APIs, and build a portfolio project for my professional growth and certification journey.

## 🚀 Features

- Netflix-inspired user interface
- Browse movies and TV shows
- Display movie information using the TMDB API
- Interactive components and navigation
- Responsive design
- Local storage for supported features
- Client-side navigation using React Router

## 🛠️ Technologies and Skills

- **HTML** — Web page structure
- **CSS** — Styling and responsive design
- **JavaScript** — Programming fundamentals and interactive features
- **React** — Components, props, state, and hooks
- **React Router** — Navigation between pages
- **Axios / Fetch API** — Making API requests
- **TMDB API** — Retrieving movie and TV show data
- **Local Storage** — Saving supported data in the browser
- **Git and GitHub** — Version control and project management
- **Deployment** — Publishing the project online

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

_Note: These commands assume your project uses React with Vite._
